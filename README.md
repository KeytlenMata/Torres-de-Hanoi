# 🗼 Torres de Hanoi - Por: Keytlen Mata

Implementación completa del clásico problema de las **Torres de Hanoi**, diseñado para demostrar el uso de **recursividad**, **estructuras de datos tipo pila** y **análisis de complejidad algorítmica**.

## 🎯 Objetivos de Aprendizaje
- Comprender el paradigma de programación recursiva
- Analizar la relación entre recursión y pila de ejecución
- Implementar algoritmos con validación de reglas de negocio
- Visualizar el comportamiento de estructuras de datos

## 🛠️ Tecnologías
- Python 3.10+
- Tipado estático (`typing`)
- Programación Orientada a Objetos
- Pruebas con `pytest`
